## 用户要求
1. 筛选内容挤在一起：重整信息分组、间距、桌面/移动层级；筛选结果和选中状态明确，支持独立清除条件和全部重置。
2. 工具详情阅读体验差：重整简介、主要操作、安装、适用场景、特点、示例、资料等信息顺序，控制阅读行宽、字号、行距、留白和移动端节奏。不要用重复小标题或冗余字段堆叠。
3. 去掉侧边栏“编辑精选”。首页精选卡片可保留，但不可制造重复浏览入口。
4. 分类图标用语义对应的 Lucide SVG（AI/代码/动画/图表/数据库/部署/手机/设计/内容/效率），不要沿用无关 Unicode 装饰符。示例入口也用相关图标。
5. 所有工具显示官方 Logo。主代理会将 Tool.logo?:string 和 Tool.logoDark?:string 写入 API，均为本站 /media/icons/ 路径。你负责统一 ToolLogo 组件，并覆盖卡片、精选、搜索结果、详情、相关工具和示例关联工具等所有出现工具标志的位置。图片 object-fit:contain，有适合品牌图标的中性底板，暗色可用 logoDark，加载失败或缺失才回退 tool.icon。不要热链外站图标。
6. Header 与侧栏重复的收藏入口只保留一个。建议 Header 保留，让桌面和移动均可见，侧栏移除；工具卡片的收藏操作仍保留。收藏列表有明确标题、数量、空状态和清除过滤回到全部收藏的路径。
7. 重点梳理使用逻辑：从目录/分类/搜索/收藏进入详情，返回恢复原筛选、关键字和滚动位置；浏览器前进后退可用；切换主导航不要留下不明的旧模式；筛选状态与 URL 一致且可分享，移动菜单选项点击后关闭，筛选移动端易用且键盘可操作。移动菜单/搜索/筛选面板妥善管理焦点、Esc、遮罩和滚动。
