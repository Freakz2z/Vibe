# 首屏与缓存

页面仍由 Cloudflare Workers 提供，D1 是公共目录的数据来源，R2 保存 Logo 与示例资源。没有更改 DNS、地区线路或购买加速服务。

## 页面加载

- Worker 读取同一份 D1 目录快照，随 HTML 输出经过转义的 JSON。正常启动直接使用该数据，无需再串行请求 `/api/catalog`。
- 首页输出概览与全部工具链接，工具详情、示例列表与示例详情使用对应共享组件输出可读正文。React 首次提交时替换预览；预览和应用共用样式与数据。
- 首屏主题脚本在页面内容之前读取本机主题，保持严格 CSP 的每次响应独立 nonce。
- 嵌入数据缺失或无效时仍请求目录 API，保留原来的错误、重试和滚动恢复流程。
- HTML 保持 `private, no-store`，没有缓存包含 nonce 的完整 HTML。

## 缓存范围

| 内容 | 策略 |
| --- | --- |
| D1 目录快照与首页概览 | Cache API，60 秒；同一节点并发冷请求合并一次读取，只共享已物化字符串，不跨请求共享 Workers 响应流 |
| `/api/catalog` | 支持 ETag、弱比较和 304；浏览器最多缓存 60 秒 |
| R2 Logo 与普通图片 | Cache API 与浏览器缓存 1 小时 |
| 带内容哈希的 R2 示例资源 | 节点缓存 1 小时，浏览器长期不可变缓存 |
| Vite 内容哈希资源 | 浏览器 1 年不可变缓存，文件名随内容变化 |
| `/api/labs/*`、访客统计与健康检查 | 不进入新增缓存，真实查询与读写验证语义保留 |

`shared/generated/build.ts` 由构建生成，以源码、目录数据、资源、依赖及配置计算指纹。新版本自动使用新的内部缓存键；相同构建可复用已有缓存。直接更改 D1 时，节点快照最多保留 60 秒。图像 URL 未改为不可变地址，避免普通 Logo 更新后被浏览器长期锁住。

只缓存完整、公共、成功的 200 响应。错误、缺失、带 Cookie、private/no-store 响应不写入缓存；缓存故障时读取源数据。R2 大对象直接流式响应，避免并发共享克隆流导致整份文件驻留内存。

## 验证

- 单元检查公共缓存命中、并发读取、失败恢复、私有/错误响应排除和 JSON 脚本转义。
- API 检查 D1/R2、目录与图像 304、独立 CSP nonce、HTML 中的概览与启动数据、内容哈希资源缓存。
- 浏览器阻断 `/api/catalog` 后正常启动与打开详情；关闭 JavaScript 后仍能看到首页数据概览。
- 对没有嵌入数据的情况继续验证接口回退、慢请求、收藏与滚动恢复。

这些改动减少请求和回源，不改变大陆用户到 Cloudflare 的跨境网络路径。没有使用本地或代理访问时间冒充大陆三网测速。
