# 站内动效约定

## 用户与目标

面向浏览、筛选和比较开发工具的电脑及手机用户。动效表达页面、结果和操作状态的变化，保持现有暖色卡片与亮暗主题。

## Flow: 浏览与反馈

入口：目录、搜索、分类、收藏、工具详情和示例目录。

1. 打开页面：标题渐显，首屏卡片依次进入。
2. 向下浏览：新进入视野的卡片只播放一次。
3. 更改筛选或搜索：结果及时更新，新卡片进入、数量与条件标签反馈。
4. 收藏或复制：图标短暂反馈，提示出现并淡出。
5. 打开搜索、分类抽屉或筛选：背景遮罩与面板进入；关闭时退出，焦点立即回到触发位置。

URL、收藏、滚动恢复、加载、空结果和错误逻辑沿用现有实现。

## Components and states

| 组件 | 触发 | 反馈 | 时长 |
| --- | --- | --- | --- |
| 页面标题 | 路径切换 | 渐显、向上 6px | 260ms |
| 目录卡片 | 首次进入视野 | 渐显、向上 10px，分组错峰 | 320ms，延迟上限 140ms |
| 数量与筛选标签 | 条件变更 | 渐显、图标反馈 | 180–220ms |
| 收藏心形 | 点击 | 只对图标弹性缩放 | 360ms |
| 复制图标、导航图标 | 点击 | 图标短促反馈 | 220ms |
| 搜索/抽屉/筛选面板 | 打开/关闭 | 遮罩淡入淡出、面板进入退出 | 160–260ms |
| 提示 | 出现/消失 | 渐显与淡出 | 160–240ms |
| 主题表面 | 主题切换 | 背景与颜色过渡 | 220ms |

默认、悬停、聚焦、选中、关闭和禁用状态保留语义。悬停时容器不位移、不缩放。手机使用相同短时序，避免大幅移动。

## Accessibility and edge cases

- 保留按钮语义、键盘操作、Esc、焦点陷阱及关闭后的焦点恢复。
- 关闭中的面板不可聚焦或交互；快速重开取消退出计时。
- 减少动态效果设置立即取消原生动画，CSS 关闭移动过渡，面板即时收起。
- 初始内容默认可见，浏览器缺少动画或观察 API 时仍可阅读和操作。
- 卸载、切换路径和连续筛选时清理动画及观察器；不观察示例 SDK 内部不断变化的 DOM。

## Implementation target and acceptance

目标：现有 React/Vite 页面；由当前维护代理直接实现，不引入新的动画依赖。

验收：实际交互反馈与退出时序、快速开关/切换筛选、键盘焦点、减少动态效果、亮暗主题、320/390px 布局、返回位置恢复和悬停稳定性。

## 示例布局

检查全部 55 个示例的桌面布局及手机横向溢出。长文本读数采用正文级字号，只有长内容才独占一行；数值保留统计卡片。

- Embla 的控制项、轮播和顺序列表占满可用宽度，翻页操作与统计放在同一底栏。
- Paper.js 的路径信息位于画布下方；PixiJS 的设置位于画布上方，运行数据紧随画布。
- Markdown、Shiki 的输入和输出等宽，较长设置项单独分组。
- Culori、TanStack Query、SWR、D1 使用顶部设置与通栏结果，避免长结果旁边留下整列空白。
- Mermaid 的长图在图形容器内滚动，成对代码块按各自内容确定高度。
